# Py Arcade Project

Динамичная 2D-игра на основе Python Arcade с системой уровней, врагами и боевой механикой.

## Описание

Это трёхуровневая игра с прогрессией, где вам нужно победить всех врагов на каждом уровне, чтобы перейти к следующему. Игра использует тайловые карты (TMX) и включает систему камеры, физику столкновений и боевую систему.

## Требования

- Python 3.8+
- arcade

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repo-url>
cd py-arcade-project
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
```

3. Активируйте виртуальное окружение:
```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

## Управление

### В игре
- **W/A/S/D** - движение персонажа
- **Левый клик мыши** - атака
- **ESC** - пауза (открывает меню с опциями)
- **M** - выход в главное меню (из экрана смерти/победы)
- **F11** - полноэкранный режим
- **R** - рестарт уровня (на экране смерти)

### В меню паузы
- **Продолжить игру** - вернуться в игру
- **Главное меню** - вернуться в главное меню
- **Выйти из игры** - закрыть приложение
- **ESC** - закрыть меню паузы

## Особенности

- **Система враждебности** - враги видят игрока в определённом радиусе и атакуют
- **Боевая система** - атаки игрока наносят урон врагам
- **Счетчик врагов** - в углу экрана отображается количество оставшихся врагов
- **Плавная камера** - камера следует за игроком
- **Физика столкновений** - стены блокируют движение
- **Система паузы** - меню паузы с несколькими опциями

## Режимы и экраны

### Главное меню
- Выбор уровней
- Выход из игры

### Выбор уровня
- Возможность выбрать один из 3 уровней
- Кнопка "Назад" для возврата в главное меню

### Игровой экран
- Счетчик оставшихся врагов в углу
- Меню паузы при нажатии ESC

### Экран смерти
- Опция перезагрузить уровень (R)
- Опция вернуться в главное меню (M)

### Экран победы
- Опция начать новую игру (R)
- Опция вернуться в главное меню (M)

## Уровни

**Уровень 1 (Level 1):** Введение в механику боя. 3 врага.

**Уровень 2 (Level 2):** Более сложная карта с большим количеством врагов. 4 врага.

**Уровень 3 (Level 3):** Финальный уровень высокой сложности. 11 врагов.

## Константы

Изменяйте значения в `src/constants.py`:
- `TILE_SCALING` - масштаб тайлов
- `ZOOM_LEVEL` - масштаб камеры (зум)
- `SCREEN_WIDTH`, `SCREEN_HEIGHT` - разрешение экрана
- `CAMERA_LERP` - скорость интерполяции камеры (от 0 до 1)

## Основные классы

### Level1, Level2, Level3
Управление логикой уровня, врагами и игроком. Обработка событий клавиатуры и мыши.

### PauseView
Меню паузы с тремя кнопками (продолжить, меню, выход).

### GameOverView
Экран смерти с опциями перезагрузки или выхода в меню.

### WinView
Экран победы с опциями начать новую игру или выйти в меню.

### Player
Класс игрока с механикой движения, атак и взаимодействия с врагами.

### EnemyKnife
Класс врага с простой AI системой (отслеживание, атака).

## Тройка механик врагов

1. **Обнаружение** - враг видит игрока в определённом радиусе с учётом препятствий
2. **Преследование** - враг движется в направлении игрока
3. **Атака** - враг наносит урон при столкновении с игроком

## Совет для игроков

- Атакуйте врагов левым кликом мыши
- Избегайте скопления врагов
- Используйте паузу (ESC) при необходимости
- В меню паузы вы сможете выйти или вернуться в главное меню
